## **📖 Information**

This is a mod for [Minecraft]-[NeoForge].<br>
It adds a simple block you can use for measuring energy transfer rates.

It has a screen always displaying the current rate to keep you up to date.

## **🔧 Manual Installation**

1. Download the latest **mod jar** from the [releases], from [CurseForge] or [Modrinth].
2. Install Minecraft [NeoForge].
3. Drop the **jar file** into your mods folder.
